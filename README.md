# 🌾 YieldSense AI
## Crop Yield Prediction & Agricultural Productivity Forecasting System

> **Infosys Virtual Internship Project**
>
> An AI-powered smart agriculture platform for crop yield prediction, weather analysis, soil assessment, crop recommendation, analytics, and agricultural reporting.

---

# 📖 Project Overview

YieldSense AI is an end-to-end intelligent agriculture platform developed as part of the **Infosys Virtual Internship Program**.

The platform helps farmers make informed agricultural decisions by combining **Machine Learning**, **historical crop yield data**, **weather information**, and **soil characteristics** to predict crop yield and provide actionable farming recommendations.

The application consists of:

- FastAPI Backend
- React Web Application
- React Native Mobile Application
- PostgreSQL Database
- Machine Learning Prediction Engine

The platform enables farmers to manage farms, generate AI-powered crop yield predictions, analyze weather and soil conditions, receive crop recommendations, and download professional PDF/CSV reports.

---

# 🎯 Project Objectives

The primary objectives of YieldSense AI are:

- Predict crop yield using Machine Learning
- Improve agricultural productivity
- Help farmers choose suitable crops
- Analyze weather conditions affecting crop growth
- Analyze soil nutrients and fertility
- Provide intelligent crop recommendations
- Generate downloadable agricultural reports
- Maintain historical prediction records
- Deliver a responsive web and mobile application
